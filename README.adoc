== Introduction

== Prerequisites
* Linux Host
* Nightly Rust (2025-09-12)
* OVMF
* qemu (x86_64)
** qemu-img
** qemu-system-x86_64

== Building/Compiling
To build a base image
[source,bash]
----
make build
----
or
[source,bash]
----
cargo build
----

to create a bootable image with an ESP
[source,bash]
----
make create-img
----

run image on qemu
[source,bash]
----
make run-qemu
----
be noted that this generates a log file
